# Code of Conduct

Veil follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.
The full text at that link is our code of conduct; this page is a summary, not a replacement.

## In short

We want participating in Veil to be a harassment-free experience for everyone, regardless of age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression,
level of experience, education, socio-economic status, nationality, personal appearance, race, caste,
color, religion, or sexual identity and orientation.

**Do:** be respectful of differing opinions and experiences, give and gracefully accept constructive
feedback, take responsibility for mistakes and learn from them, focus on what is best for the community.

**Don't:** use sexualized language or imagery, troll, insult or make personal or political attacks,
harass publicly or privately, publish others' private information without their explicit permission
(in a data-protection project this includes pasting someone's real data into an issue), or behave in any
way that would reasonably be considered inappropriate in a professional setting.

## Scope

All project spaces (issues, pull requests, discussions, chat) and anywhere you officially represent the
project.

## Enforcement

Report unacceptable behavior privately to the maintainers (see the repository profile, or use the
private contact listed in [SECURITY.md](SECURITY.md) with the subject `VEIL CONDUCT`). All reports are
reviewed promptly and kept confidential. Maintainers follow the Contributor Covenant's enforcement
guidelines: correction, warning, temporary ban, permanent ban.
